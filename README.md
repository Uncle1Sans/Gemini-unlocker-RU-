Gemini Unlocker 🚀
Gemini Unlocker — это простая и удобная утилита для Windows, которая автоматизирует настройку DNS-серверов для обхода ограничений Gemini. Программа сделана на базе конфигураций и адресов с сайта xbox-dns.ru.

Вам больше не нужно вручную заходить в параметры сети, искать активный адаптер и вбивать цифры — утилита сделает всё за вас в один клик.

🛠 Основные возможности
Автоматический поиск сети: Программа сама определяет, через какой адаптер вы сейчас сидите в интернете (Wi-Fi или проводной Ethernet).

Включение в 1 клик: Кнопка «ВКЛЮЧИТЬ ДОСТУП» автоматически прописывает нужные DNS-адреса (111.88.96.50 и 111.88.96.51).

Быстрый откат настроек: Кнопка «ВЫКЛЮЧИТЬ ДОСТУП» мгновенно возвращает настройки вашего интернета в исходное состояние (включает автоматическое получение DNS по DHCP).

Удобный мониторинг: Прямо в интерфейсе отображается текущий статус вашего подключения в реальном времени.

Встроенная справка: По кнопке «ИНФО» открывается окно с инструкцией.

💻 Технологический стек
Программа написана на Python с использованием следующих библиотек:

tkinter и Pillow — для создания кастомного графического интерфейса в стиле темного консольного терминала.

subprocess — для незаметного и безопасного выполнения системных команд (PowerShell и Netsh).

ctypes — для автоматического запроса прав Администратора (так как Windows не позволяет менять сетевые настройки без повышенных привилегий).

🚀 Как запустить / Скомпилировать в .exe
Если вы хотите запустить программу из исходного кода, вам понадобятся Python и библиотека Pillow:

Bash
pip install pillow
python main.pyw
Сборка в один независимый .exe файл:
Для компиляции проекта в готовый исполняемый файл используется PyInstaller. Команда для терминала (все ресурсы вшиваются внутрь файла, консоль скрыта, автозапрос прав админа включен):

Bash
python -m PyInstaller --onefile --noconsole --uac-admin --add-data "icon.png;." --add-data "background.jpg;." --icon=icon.ico main.pyw
⚠️ Известные нюансы
Права администратора: Программа обязательно запросит права админа при старте — это нормально и необходимо для работы утилиты netsh.
